## 4. 排障轨迹

| 现象 | 根因 | 对策 |
| --- | --- | --- |
| 中性化单测 `dates=0, skipped=300`，全部交易日被跳过 | 三因叠加：合成股票数低于 `NEUTRALIZATION_MINIMUM_STOCKS=20`；缺 `turnover_rate` 导致 `turnover_20` 全 NaN；成交量恒定导致 `price_volume_corr_20`、`volume_price_divergence_60` 全 NaN。中性化要求全部因子使用**共同有效样本**，任一因子结构性缺失会把覆盖率清零 | 修正测试数据的真实度（补 `turnover_rate`、让成交量按正弦波动）；同时在生产代码加 `factor_missing_dates` 计数，把“因子整体缺失”与“截面不足”分开报告 |
| 中性化状态只显示“截面不足或因子缺失被跳过”，看不出是哪一种 | 计数器缺失 | `services/neutralization.py` 增加 `factor_missing_dates`，并在 `status` 中分别措辞；真实数据实测 74 个跳过日中 60 日属因子缺失 |
| 组合回测出现“成交了股票池外的股票”的隐患（推理发现，非测试暴露） | `run_portfolio_strategy` 对整个面板打分，却只为裁剪后的股票池准备价格矩阵，排序可能选中没有行情、根本无法成交的股票，形成静默未成交 | 裁剪后同步裁剪 `panel`（保留 `attrs`），并新增回归测试 `test_trimmed_universe_is_also_the_scoring_universe` 断言成交集合 ⊆ 保留股票池 |
| 扫描页把无量纲排序分显示成“20日超额收益” | 排序目标输出是相对分数，页面沿用了回归口径的列名 | `services/scanning.py::validated_return` 按 `score_kind` 分流：排序模型显示同日截面百分位，回归模型才显示预期超额收益；页面列名改为“20日预测值”并补口径说明 |
| 滚动重训记录只写“未通过验证”，无法判断哪条门槛没过 | 训练日志只记录 `status` | `walk_forward_scores` 随记录写入 `rank_ic`、`ndcg_ratio`、`mae`、`validation_rule`、`training_dates`；扫描页把嵌套结构摊平成一张表；新增单测 `test_training_log_records_why_a_block_scored_nothing`（用固定种子噪声截面强制走到被拦分支，断言 `rejected > 0`，避免空跑通过） |
| 冒烟第一区段提示“截面样本不足” | 首个打分点只有 320 个可用交易日，扣除特征预热与 20 日标签成熟期后仅 226 个带标签交易日，低于 `fit_panel_model` 的 240 日下限 | 属预期行为，不改门槛；改为在重训记录里显式给出 `training_dates`，页面可直接看到差多少 |
| `ModuleNotFoundError: No module named 'pyarrow' / 'duckdb'` | 用了全局 Python 或根目录 `.venv` | 统一改用 `quant\.venv\Scripts\python.exe` |
| `ModuleNotFoundError: No module named 'services'` | 冒烟脚本在临时目录执行 | 运行时加 `PYTHONPATH=quant` |

网络相关：`logs/market_data.log` 可见“行情连接异常断开，尝试公开行情域名直连 host=82.push2.eastmoney.com；系统代理设置保持不变”，属既有的代理/直连回退路径，不影响本次结论。

## 5. 遗留与限制

- 组合回测的净值为“本次实际采集股票池”内按模型排序的结果，仍不是历史成分股组合，不能消除幸存者偏差。
- 历史市值由“当前流通市值 ÷ 当前价 × 历史收盘价”近似，行业使用当前申万一级分类，均非严格点时数据；真实数据下中性化覆盖率 94.6%，低于此阈值会自动退回截面 Z 分数因子。
- 费率按比例近似，未模拟最低佣金、整手与盘口深度。
- 本次仅 33 只股票可用，逐区段滚动验证被 Rank IC 门槛拦住而拒绝建仓；要在真实数据上产出可复核的组合净值，需要先扩充股票池到数百只。
