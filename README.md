# A 股量化分析与选股研究系统

一套在 Windows 本地运行的 A 股量化研究工具：Web 界面基于 Streamlit，行情取自东方财富、新浪财经等公开接口，建模使用 LightGBM / XGBoost，统计检验使用 Statsmodels。

系统的原则是**不伪造结果**：拿不到行情就显示错误或标注为缓存，模型没通过样本外验证就不输出评分，没有统计依据就不生成套利信号。所有页面都会显示数据来源、行情时间和采集时间。

> 各模块的详细口径、限制与实现说明见 [docs/详细说明.md](docs/详细说明.md)。

## 功能

### 页面一 · 个股分析

- 按代码或名称搜索 A 股，展示最新价、涨跌幅、成交量额、当日开高低收。
- 日 K / 周 K 及成交量图表，常用技术指标与传统多因子指标。
- LightGBM 与 XGBoost 的预测、特征重要性、时间序列样本外验证结果。
- 参考买入区间、初始止损、止盈与趋势退出条件（由 ATR 等明确规则计算，不换算绝对价格）。
- 单标的回测，以及配对股票的统计套利研究。

### 页面二 · 量化选股

- 扫描沪深主板、创业板、科创板或自定义股票池，默认排除 ST、退市整理与数据不完整股票。
- 结果展示多因子评分、两个模型的排名、预测周期、参考入场/止损/退出条件与主要风险，可跳转到页面一。
- 扫描前可选训练目标（排序 / 回归 / 自动择优）、滚动训练窗口长度、是否启用市值与行业中性化。
- 可勾选在同一轮扫描后运行 **Top-N 组合回测**，直接查看组合与基准净值、换手率、费用拖累、未成交笔数，以及每笔成交和每段训练窗口的明细。

### 页面三 · 自选与持仓

- 自选增删与监控开关；分批录入买入日期、价位、股数、可卖股数与费用。
- 汇总成本与带源时间的参考浮盈亏；持仓编辑使用行锁与版本号防止覆盖，删除保留审计记录。

### 页面四 · 盘中监控

- 3~60 秒快照轮询、30~300 秒分钟线同步，独立后台任务，关掉浏览器页面不会停止。
- 单股规则使用卡尔曼滤波估计参考价，遵守 T+1 与手工确认的可卖数量。
- 配对监控只用当日之前的历史检验协整与对冲比例稳定性，未确认借券条件时只显示观察。

## 建模与工程要点

**排序目标替代回归目标。** 直接用 MSE/MAE 回归未来收益时，树模型在全市场普涨下会退化成"全线看多"。因此默认把每个交易日的截面收益按分位映射为 5 级相关度，用 LambdaMART（LightGBM）或 `rank:ndcg`（XGBoost）直接优化截面内排序，`group`/`qid` 为交易日——"看多"只在同日截面内部成立。排序输出是无量纲的相对分数，页面按同日截面百分位展示，不会当成预期超额收益；只有回归目标才给出有量纲的预期收益。也可选「自动择优」同时训练两种目标，按样本外 Rank IC 择优，并把两边的指标写进结果供复核。

**滚动窗口重训（Walk-Forward）。** 废弃静态全量训练，每次重训默认只取最近 750 个交易日（约 3 年）的样本，让策略跟上 A 股风格切换。窗口按完整交易日截取，窗口内训练标签的结束日仍必须严格早于测试起日，不会因截断而泄漏未来；设为 0 表示使用全部历史。

**市值与申万一级行业中性化。** 对每个交易日的股票截面，以流通市值对数与行业哑变量做多元线性回归，取残差作为纯净 Alpha 因子，避免模型只学到"买大市值白马"或"追热门板块"。同一天的全部因子使用相同有效样本，覆盖率低于 50% 时自动退回截面 Z 分数因子，并把跳过原因（截面不足 / 因子整体缺失）写入上下文。另补充短期反转（1 日 / 3 日收益）、Amihud 非流动性、量价背离等特征。

**Parquet + DuckDB 列式存储。** 大规模面板不再走 SQLite 行式存储：清洗后的日线、因子面板与市值行业暴露统一落盘为 Parquet（zstd 压缩，按 `adjustment=*/code=*.parquet` 分区，先写临时文件再原子替换）。DuckDB 把 Parquet 目录映射成视图做只读即席查询。未安装 duckdb 时退回口径一致的 pandas 向量化实现，并有等价性单测。

**加载阶段异常清洗。** 前复权序列出现超过板块涨跌幅上限 1.2 倍的跳空时按复权口径剔除（上市初期不参与判定）；连续停牌达 20 个交易日标记为长期停牌，不进入当日截面；全天无振幅且触及涨跌停的一字板标记为流动性锁定，不假设成交。清洗只标注与剔除不可信 K 线，不改写原始价格。

## 交易摩擦与风控口径

组合回测按每日截面把模型排序融合后取前 N 名（默认 20）等权持有，单股仓位上限默认 5%，超出部分留现金、不放大杠杆。撮合严格模拟 A 股制度：

- **T+1**：当日开盘买入最早次日开盘卖出。
- **涨跌停**：开盘一字涨停不假设买入成交，开盘一字跌停不假设卖出成交。
- **停牌**：不交易，按最近收盘价估值。
- **成本**：卖出收 0.05% 印花税，买卖双边各收 0.03% 佣金与 0.1% 滑点，逐笔记录未成交笔数。

打分股票池与撮合股票池强制一致：流动性筛选裁剪股票池后，截面面板同步裁剪，避免排序选中根本没有行情、无法成交的股票。

**模型验证不通过就不输出评分。** 排序目标要求每日 Rank IC > 0.02 且 HAC t > 1.645、NDCG@截面前 20% 高于随机基线 5% 以上、Top 超额为正并优于池均值、Top-Bottom 为正、至少 40 个样本外交易日；回归目标仍按 MAE 中位数基线判定。滚动重训的每一段都会把实际检验数值（`rank_ic`、`ndcg_ratio`、`mae`、`training_dates`、当时生效的验证规则）写进记录，被门槛拦下时能直接看出是哪一条没过、差多少。

## 技术栈

| 用途 | 选型 |
| --- | --- |
| 界面 | Streamlit |
| 数据处理 | Pandas、NumPy |
| 建模 | LightGBM、XGBoost（LambdaMART / `rank:ndcg`） |
| 统计检验 | Statsmodels（协整、HAC） |
| 面板存储 | Parquet + DuckDB |
| 本地缓存 | SQLite |
| 业务数据 | PostgreSQL（自选、持仓、监控、回测存档） |

行情获取、因子计算、模型预测、策略信号与页面展示是分离的模块。

## 快速开始

需要 64 位 Python 3.11 或更新版本。Windows 下双击 `run.bat` 会自动创建虚拟环境、安装依赖并启动。

手动执行：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

Linux / Nginx 部署见 [deploy/README.md](deploy/README.md)。

首次启动会要求登录。账号不提供网页注册，必须用命令行创建：

```powershell
.venv\Scripts\python.exe manage_users.py create admin --temporary
```

临时密码首次登录后强制修改为至少 12 位。

## 配置数据库

业务数据（自选、持仓、盘中监控、回测存档、账号）保存在 PostgreSQL 的 `public` 模式，首次启动会自动执行 `sql/` 下的建表脚本，不会覆盖已有数据。

1. 复制模板并填入自己的连接信息：

   ```powershell
   copy config\database.example.json config\database.local.json
   ```

   ```json
   {
     "host": "127.0.0.1",
     "port": 5432,
     "dbname": "quantify",
     "user": "postgres",
     "password": "请填写数据库密码"
   }
   ```

2. `config/database.local.json` 是私有文件，已在 `.gitignore` 中排除，**不要提交**。仓库内只保留占位模板 `config/database.example.json`。

3. 也可以改用环境变量覆盖其中任意一项，环境变量优先级更高：

   | 变量 | 含义 |
   | --- | --- |
   | `QUANT_PG_HOST` | 主机 |
   | `QUANT_PG_PORT` | 端口 |
   | `QUANT_PG_DBNAME` | 数据库名 |
   | `QUANT_PG_USER` | 账号 |
   | `QUANT_PG_PASSWORD` | 密码 |

密码只保存在本地配置文件或环境变量中，不写入源码，也不会进日志。数据库不可用时会明确报错，不会退回临时内存假装保存成功。

## 目录结构

```text
quant/
├── app.py                    # Streamlit 入口（登录与导航）
├── manage_users.py           # 终端创建 / 重置 / 禁用账号

├── sql/                      # PostgreSQL 建表迁移脚本
├── tests/                    # 单元测试
├── test_records/             # 按日期的测试记录（脚本、数据画像、结果存证、排障轨迹）

```

## 已知限制与免责声明

- **不构成投资建议。** 扫描与策略信号是研究结果，历史回测不代表未来收益。
- 行情接口免费且无 SLA，可能限流、延迟或变更；实时行情、最近收盘行情与缓存行情会被明确区分，过期数据不会用于生成扫描预测。
- 基本面历史披露数据未接入，估值、盈利质量与点时财务因子不参与评分；相对强弱目前只对比沪深 300，行业基准未接入。
- 组合回测的净值为"本次实际采集股票池"内按模型排序的结果，不是历史成分股组合，**不能消除幸存者偏差**。
- 历史市值由"当前流通市值 ÷ 当前价 × 历史收盘价"近似，行业使用当前申万一级分类，均非严格点时数据。
- 费率按比例近似，未模拟最低佣金、整手与盘口深度；未完整模拟历史 ST 变化、IPO 特殊涨跌幅与精确分红税。
- 分钟级信号不等同于交易所级高频交易，未接入逐笔行情、委托、撤单或券商回报，不会自动下单。
