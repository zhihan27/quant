量化系统本次修改总结
====================

审阅范围
--------
本总结覆盖 feature.txt 中的三项工作：历史市值与估值特征研究、每日人工调仓清单、市场风格与微观状态识别，以及随后对个股因子分析页的优化。

核心结论
--------
1. 市值和估值已经具备进入模型训练与预测链路的实现，但默认关闭。只有历史数据满足点时要求、覆盖率达标，并且当前配置通过独立留出验收后，新增风格特征才会实际进入生产模型。界面上的勾选或行情快照本身不代表已经入模。
2. 个股页分别展示量价时序评分、市值估值观察值、历史点时值与实际模型特征清单，避免把当前快照误认为历史因子或评分结果。
3. 增加人工调仓任务单和市场状态诊断。任务单只供人工盘前复核，不会发送交易指令；市场状态在数据不足时明确降级并记录原因。
4. 没有真实授权的历史数据和独立验收结果时，不能据本次代码或合成测试数据声称市值/估值因子提高了收益。

主要实现
--------

一、历史市值与估值因子

- 行情快照增加 PE(TTM)、PB、PS(TTM)、总市值和流通市值，并保留来源、单位和数据有效状态。实时数据缺失时仍明确显示缺失，不用其他字段代替。
- 新增历史估值数据适配、单位规范化和点时重建逻辑。历史记录要求包含来源、采集时间、可用时间、修订版本、单位、质量与 PIT 核验标记；财务公告按公告后的下一实际交易日生效。
- `daily_basic` 提供的历史估值倍数保留供追溯，但无法确认其财报修订版本时标记 `value_pit=False`，不作为已核验价值特征。只有股本事件与财报版本均通过 PIT 核验，才可重建历史价值特征。
- 模型新增五项候选特征：总市值对数、流通市值对数、盈利收益率 E/P、账面市值比 B/P、销售市值比 S/P。亏损公司的负 E/P 保留；无效市值、非正净资产或非正收入按规则记缺失，不以 0 伪装成有效值。
- 面板对每个截面进行配置化截尾和标准化，并执行覆盖率检查。市值与估值开关默认关闭。模型上下文记录候选列、真实 `features_used`、覆盖率、排除原因和配置指纹；规则或独立验收变化后拒绝复用不匹配的旧模型上下文。
- 增加四组对照实验入口：基础、基础加市值、基础加估值、基础同时加入两类特征。配置选择和最终验收区间隔离；验收失败或中断不会打开新增生产特征。
- 漂移监控仅在存在可靠点时 E/P、B/P、S/P 数据时计算估值分布；无此数据时记录“未接入”及原因。

二、个股因子分析页

- “走势打分”改为“量价走势打分”，与市值估值特征分开展示。
- 展示五项市值估值特征的当前行情观察值、同股同日历史点时值、来源与单位状态、缺失原因，以及各预测周期模型实际使用的特征。
- 快照代码或单位不匹配时不显示该快照因子；历史估值只从本地面板按股票读取，不在逐股扫描中额外触发网络请求。
- 基本面状态文案由当前个股的真实有效预测和模型特征清单生成。仅仅打开配置开关，或模型训练列表含有某列但该股没有有效预测，都不会显示为“已生效”。

三、每日人工调仓任务单

- 使用完整全市场排名生成调出、调入、维持和待核查清单，页面行数截断不影响 Top N 判断。
- 调入要求模型有效、同日有效行情、成交额达到配置门槛、趋势与交易风控通过。缺失排名、过期数据或模型降级不会被推断成跌出排名，也不会生成买入任务。
- 卖出参考包括持仓成本下固定 8% 初始止损、收盘跌破 20 日均线和跌出 Top N；同时显示可卖数量、参考浮盈亏和待核查原因。
- 清单供下一实际交易日人工复核。停牌、涨跌停、开盘价格和券商可卖数量仍需执行前确认；本功能不自动下单。

四、市场状态与数据库

- 每日扫描对齐中证 1000 与沪深 300 的共同交易日，计算 20 日相对动量；并计算扫描样本成交额、换手率近 60 日分位及申万一级行业涨幅/成交额排名。
- 状态数据区分全市场和扫描样本范围。指数、交易日、样本覆盖或行业数据不足时记录警告，不填 0、不把成交额解释为资金净流入，也不把当前行业分类冒充历史点时分类。
- 新增 PostgreSQL `public.quant_market_regime` 表及 `sql/006_market_regime.sql` 迁移，在选股页和模型健康页展示最近扫描状态。

五、关键逻辑示例

个股页面只有在模型预测有效且真实特征清单包含对应风格因子时，才报告该因子已参与当前个股预测：

    effective = bool(item.get("validated")) and has_signal
    effective_columns = (
        [name for name in actual if name in (item.get("features_used") or [])]
        if effective else []
    )

历史估值特征在重建时要求对应的历史版本通过 PIT 核验；未核验时保留缺失状态，不使用当前快照回填：

    if historical and name in VALUE_COLUMNS and not _is_verified(row.get("style_value_pit")):
        return "历史财报披露或修订版本未核验"

验证结果
--------
- 2026-10-18，在启用 PostgreSQL 隔离集成测试的环境下运行完整测试集：613 项通过。
- README 记录本次全量测试结果。测试结果验证实现行为，不代表真实历史估值覆盖或策略收益已通过业务验收。

审阅时请关注的边界
------------------
- 当前市值/估值特征默认关闭；没有匹配当前规则的独立留出验收记录时不会用于生产模型。
- 当前行情 PE/PB/PS 与市值是观察快照，不能代替历史点时数据。历史数据的接口权限、覆盖范围和修订版本需由部署环境实际核实。
- 估值重建依赖来源可靠且版本可追溯的历史股本和财务公告数据；未满足条件的数据不会因导入或面板落盘而自动成为可用因子。
- 市场行业分类及部分行情数据有来源和覆盖限制；市场状态是诊断信息，不是模型失效证明或交易信号。
- 调仓任务单是人工研究辅助，不构成投资建议或自动交易功能。
